## Summary


| Category            | Purpose                                       |
| ------------------- | --------------------------------------------- |
| LLMs                | Foundation models for AI applications         |
| Agentic AI          | Frameworks for autonomous AI agents           |
| RAG                 | Connect LLMs to external knowledge            |
| Embeddings          | Convert data into vector representations      |
| MCP                 | Standardized tool and context communication   |
| AI Security         | Guardrails, prompt protection, content safety |
| Observability       | Tracing, evaluation, monitoring, debugging    |
| Memory              | Persistent memory for AI agents               |
| AI Agent Frameworks | Build production-ready AI agents              |
| Automation          | Workflow orchestration and integrations       |
| Vector Databases    | Store and retrieve embeddings efficiently     |
